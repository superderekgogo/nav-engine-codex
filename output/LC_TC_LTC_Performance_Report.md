# LC / TC / LTC 组合导航性能评估

数据集重放：158,328 个 INS 输出样本，1,564 个 RTK 历元；统计生成于 2026-10-24。三种模式独立配置、独立重放。

## 模式定义与处理量

| 模式 | 实际滤波更新 | RTK 解输入 | TDCP 输入 |
|---|---|---:|---:|
| LC | RTK 位置与速度松组合更新 | 是 | 否 |
| TC | 卫星级 L1/L2 TD-DDCP 几何残差直接更新 | 否 | 是 |
| LTC | RTK 位置松组合；L1 TDCP 解算相邻历元天线 Δposition，再除以 Δt 得到区间平均速度更新 | 是（位置） | 是（仅 L1 用于 WLS） |

LTC 的 L1 观测先构造模型 `y = c + A·Δr + ε`，用共享 pivot 相关协方差及前历元位置不确定度进行加权最小二乘，要求至少 4 条有效 L1 行且几何矩阵满秩；得到 Δr 后转换到 NED，并以 `Δr/Δt` 作为区间平均速度观测。滤波预测量使用前后 INS 端点速度均值 `0.5(vₖ₋₁+vₖ)`，而非仅用当前端点速度。该速度更新对应 H=0.5I；前历元速度协方差按 0.25 投影入观测噪声。

## Innovations interpretation

按目前噪声/相关性近似，LTC 的 L1 派生速度更新 normalized RMS=0.878、mean NIS/dof=0.831，接近 1，初步看与设定噪声量级相符；LC RTK P/V 的 normalized RMS=1.283、NIS/dof=2.798，提示 RTK 量测噪声可能偏小或存在未建模异常；TC TD-DDCP 的 normalized RMS=0.199、NIS/dof=0.048，创新明显小于预测不确定度，当前 TC 协方差很可能偏保守，尤其应复核时间差分噪声、共享参考状态协方差投影和相关处理。上述 NIS 仅作诊断，不是独立精度评价。

## 解释与限制

- LTC 这次实际接受 1,557 个 L1 派生速度更新历元（4,671 个速度分量）；另有 6 个未能用于该更新，原因是有效 L1 行数不足或几何条件不合格。RTK 位置仍在所有 1,564 个有效历元更新。需要结合 CSV 和日志定位每个拒绝原因；当前输出只记录计数，没有逐原因诊断。
- LTC 的 TDCP 派生速度与 RTK 位置的误差存在数据相关性；当前实现没有前后状态完整互协方差，也没有 RTK 与相位之间的完整互协方差，因此 covariance/NIS 是近似评估。
- 三种模式的数值输出及协方差不能直接当作独立精度真值比较。LC/LTC 使用同一 RTK 引擎输入；没有独立 rover 位置、速度或姿态参考数据，不能据此认证绝对定位、速度或姿态精度。
- 目前报告中的 innovations 是更新前残差；NIS 使用实现内近似的预测协方差。normalized RMS 偏离 1 可提示噪声模型/相关性仍需调整，但受相关行与参考状态误差近似影响。
- 图表：`output/lc_tc_ltc_performance.png`。分模式原始结果分别在 `ins_rtk_nav/build/mode_lc/`、`mode_tc/`、`mode_ltc/`。

## 结论

三种模式均可通过 JSON 独立切换和运行。按当前数据，LTC 的 L1 TDCP 区间平均速度更新已成功进入滤波器，和 RTK 位置松组合并行工作；它不是 TC 的卫星级范围残差更新，也没有把 RTK 速度默认混入 LTC。LTC 最终位置协方差为约 0.030 m 的 3D 1σ（N/E/D 边际组合），可视为滤波器内部不确定度指标，不能解读为已验证的 3 cm 实际定位误差。
